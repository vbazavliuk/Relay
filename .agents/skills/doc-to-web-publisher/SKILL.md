# Technical Document-to-Web & SEO Publisher (`doc-to-web-publisher`)

This skill streamlines the conversion of raw technical documents into search-engine-optimized, semantically structured, and accurately translated web pages for industrial and commercial websites.

---

## 🎯 Core Capabilities

1. **Document-to-Web Conversion**:
   - Extract messy specs, equipment tables, and manufacturer catalogues from PDF/Word/Excel into clean, accessible HTML/WordPress markup.
2. **Multilingual Precision Audit (UA / RU / EN)**:
   - Ensure industry-specific terminology (industrial refrigeration, compressors, chillers, refrigerants) is translated with technical accuracy without machine-translation artifacts.
3. **On-Page Technical SEO**:
   - Structure single-H1 pages, semantic H2/H3 hierarchies, schema markup, meta titles, descriptions, and optimized anchor text.
4. **Local WordPress Assistance**:
   - Guide page creation, theme template customization, and content entry in Local WP environments.

---

## 📋 Standard Workflow

*Consult checklist: [references/seo-and-content-checklist.md](./references/seo-and-content-checklist.md)*

### Phase 1: Ingestion & Structuring
1. Parse technical parameters from the provided document.
2. Convert tables into responsive HTML tables with formatted unit measurements ($kW$, $m^3/h$, $bar$, $^\circ C$).
3. Highlight key competitive advantages, applications, and operational guarantees.

### Phase 2: Multilingual Terminology Cross-Check
1. Check terminology alignment across language versions (Ukrainian primary, Russian, English).
2. Validate that localized URLs and navigation anchors point to matching language routes.

### Phase 3: On-Page SEO Optimization
1. Compose primary Meta Title and Meta Description adhering to length limits.
2. Format `<h1>` to capture primary search intent.
3. Check and insert descriptive `alt` tags for all product and schematic images.
