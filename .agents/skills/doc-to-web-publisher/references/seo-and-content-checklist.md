# Document-to-Web & SEO Quality Checklist

---

## 📄 1. Document Extraction & Content Structuring
- [ ] Parse tables, equipment specifications, and technical parameters into semantic HTML tables (`<table>`, `<thead>`, `<tbody>`).
- [ ] Convert raw text dumps into readable subsections with clear value propositions and call-to-actions (CTAs).
- [ ] Format equipment model lists, refrigerants, temperature ranges, and power specs consistently.

---

## 🌐 2. Multilingual Quality & Terminology Audit (UA / RU / EN)
- [ ] **Technical Term Consistency**:
  - Ukrainian: *промисловий холод, холодильний компресор, конденсатор, повітроохолоджувач, холодоагент*.
  - Russian: *промышленный холод, холодильный компрессор, конденсатор, воздухоохладитель, хладагент*.
  - English: *industrial refrigeration, refrigeration compressor, condenser, unit cooler, refrigerant*.
- [ ] Eliminate clumsy machine-translation calques and unnatural phrasing.
- [ ] Ensure corresponding localized URLs, breadcrumbs, and alternate language hreflang links match.

---

## 🎯 3. On-Page SEO Checklist
- [ ] **Title Tag**: Primary Keyword + Secondary Keyword | Brand (50-60 chars max).
- [ ] **Meta Description**: Engaging summary with target keywords and CTA (130-160 chars).
- [ ] **Heading Hierarchy**: Exactly one `<h1>` per page. Subsections nested logically (`<h2>` ➔ `<h3>`).
- [ ] **Image Alt Attributes**: Meaningful, descriptive alt text containing domain keywords.
- [ ] **Internal Linking**: Contextual links to related products, services, and contact pages.
